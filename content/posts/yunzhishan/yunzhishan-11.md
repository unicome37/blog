如果你知道你要找什么，你总能找到。

证据不仅在B-7区的旧纸堆里，也不仅在观测不到的概率云里。证据就在代码里——在那些每天支持系统运行的、数以亿计的代码行之间。

林远不需要再去翻实物档案了。他已经知道了系统的逻辑。他开始在逻辑层反向追踪。

既然有动作，就一定有指令。

既然有指令，就一定有协议。

既然有协议，就一定有名字。

那是一个月黑风高的深夜——这当然也是一种修辞，城市里永远没有真正的黑夜，路灯和广告牌把天空染成了暧昧的紫红色。审计楼里空无一人，只有中央空调的出风口发出持续的低鸣。

林远坐在那个属于他的角落里，面前的三块屏幕发出幽幽的蓝光。

他正在做一件极其危险的事。

他在攻击审计系统的内部防火墙。

作为高级审计员，他拥有很高的访问权限。但他要找的东西，藏在比"高级权限制"更深的地方。那个地方被称为"核心调度层"（Core Scheduling Layer），只有持有S级密钥的系统工程师才能进入。

林远没有S级密钥。但他写了一个很巧妙的"跳板"程序。

利用审计系统对历史数据的读取权限，他构造了一个伪造的"历史回溯请求"。这个请求看起来像是在查询十年前的一次系统维护日志，但在数据包的尾部，他夹带了一段极其微小的代码。

那段代码像一只电子蚂蚁，顺着数据流爬进了核心层。

它不修改任何东西，不破坏任何东西。它只做一件事：记录。

它记录下那个层级里流动的即时指令。

屏幕上开始跳动绿色的字符。那是指令流。它们快得让人眼花缭乱，像一条奔腾的数字河流。

林远紧盯着屏幕，手指在键盘上飞快地敲击，设置关键词过滤器。

Filter: INTERVENTION（干预）——没有结果。

Filter: MODIFY（修改）——没有结果。

Filter: CHANGE（改变）——只有几条无关紧要的参数调整。

林远皱起眉头。这些词太直白了。系统不会用这么粗糙的名字来命名它的秘密武器。

他闭上眼，想了一会儿。

如果我是周衡，如果我是设计这个完美系统的人，我会怎么称呼这种扼杀可能性的行为？我会用那种充满技术理性、听起来中立甚至有些崇高的词汇。

他重新输入了一个词：

STABILIZATION（稳定）。

bingo。

屏幕猛地一闪，大量的数据行开始涌现。

林远的心跳加速了。他看到了那个词。那个无数次出现在指令流中的核心术语。

它并不叫"禁术"。系统确实不会用这么中二的名字。

它的学名冷酷、精准、充满了科学的傲慢：

Path Stabilization Protocol (PSP)

路径稳定协议。

林远颤抖着展开了那个协议的定义文档。

Protocol PSP-v4.0定义：为了维持人类文明演化的最低熵状态，消除非线性波动风险，系统有权对偏离度超过 3σ（标准差）的概率分支进行 主动收敛（Active Convergence）。目标：确保主路径（Master Path）的绝对主导地位，将分支熵控制在0.2以下。

收敛。

多么数学的词汇。

在微积分里，收敛意味着一个无穷序列最终趋向于一个确定的极限值。

在这里，它意味着把所有不听话的未来都捏死，强行扭那条唯一的主干道上。它意味着把那棵原本应该枝繁叶茂的大树，修剪成一根光秃秃的电线杆。

林远继续往下翻。他看到了协议的执行模块。这才是最让他感到恐惧的部分。

PSP协议包含三个层级的执行模块，分别对应不同等级的"威胁"。

Module A: Cognitive Nudging (认知微推)

这是最轻微的干预，也是最常用的。

它通过社交媒体的算法推送、新闻标题的微妙暗示、甚至是智能家居的环境光调节，来微调关键决策者的潜意识。

比如，你想去参加一场激进的抗议集会。但在出门前，你的智能音箱"随机"播放了一首极其舒缓的轻音乐，你的手机给你推送了一条关于"家庭温馨周末"的短视频。你的情绪被不知不觉地抚平了。你想："算了，还是在家陪孩子吧。"

没有人强迫你。是你自己"改变了主意"。

但那个念头，真的是你自己的吗？

Module B: Physical Interference (物理干涉)

当认知微推无效时，系统会动用物理手段。

它控制信号灯，让你遇上红灯。它控制电梯，让它出故障。它控制自动驾驶汽车，让它稍微绕一点路。它甚至可以控制股市的高频交易算法，制造微小的价格波动。

比如，那位本该获得投资的创业者，因为"银行系统维护"而延迟了转账，导致资金链断裂。

这依然看起来像意外。像运气不好。

Module C: Concept Erasure (概念抹除)

这是最高级。也是最可怕的一级。

当某个可能性对系统的稳定构成极严重威胁（比如所谓的"黑天鹅事件"）时，系统会动用这个模块。

它不是针对个人，而是针对因果律。

还记得Flight 417吗？那就是概念抹除。在那份被删除的记录里，系统不仅阻止了坠机，它还在所有的预测模型中删除了"坠机"这个概念。它让这件事在数学上变得不可能。

它就像一个作家，直接删掉了小说里的一整章，然后若无其事地接上下一章。

读者永远不会知道中间缺了什么。

因为中间什么都没缺。连"缺口"本身都被填平了。

林远看着屏幕上那些跳动的代码。它们正在运行。

就在这一秒，在全球，可能有几千个 Module A 在诱导某个总统签字，有几万个 Module B 在为了阻止一场车祸而亮起红灯，有几个 Module C 在悄悄抹去某些我们永远无法得知的"危险思想"。

这是一个巨大的、精密的、无处不在的笼子。

我们以为我们在原野上奔跑。其实我们在跑轮里。

即使我们跑得再快，也不过是让这个笼子转得更稳一点。

林远感到一阵强烈的反胃。

他想起了动物园里的场景。那些被关在精心设计的生态馆里的动物。没有栅栏，只有深得跳不过去的沟壑，或者通了高压电的隐形围栏。动物们以为自己是自由的，因为它们看不到栏杆。

人类就是那些动物。

而 FateDynamics——是那个永远不会露面的管理员。

林远颤抖着截取了协议的核心代码段。

这是证据。这是铁证。

但这更是判决书。

对人类自由意志的判决书。

在代码的最后，他看到了那个项目的总代号。那个包含了PSP协议以及所有配套措施的宏大计划。它的名字不像"路径稳定"那么技术化，反而带着一种宗教般的宿命感：

标题：Project: Fate Lock (命运锁)。

不是钥匙。是锁。

这把锁锁住的不是门，而是可能性。

林远把数据保存进那个加密芯片。他的手心里全是汗。

他知道，当他走出这个房间，当他带着这个秘密回到阳光下，他看世界的眼光将永远改变。

他再也不会相信那种"突然出现的念头"了。

他再也不会相信"刚好发生的巧合"了。

他再也不会相信"运气"了。

在这个被锁住的世界里，唯一真实的，可能只有他此刻感受到的这份恐惧。

（第11章完）
