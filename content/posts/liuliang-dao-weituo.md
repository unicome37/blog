过去二十多年，我们已经习惯用“流量”理解互联网。

谁拥有更多用户，谁拥有更多注意力；谁能够把注意力导向商品、广告和交易，谁就能够获得更大的商业价值。

搜索、社交、电商、短视频，本质上都在争夺同一件东西：

**人在作出决定以前的那段注意力。**

所以互联网时代最重要的资产，曾经是入口。

有了入口，就有流量。

有了流量，就可以分发。

有了分发，就可以变现。

但最近在想 AI Agent 时，我越来越意识到，下一阶段发生的变化可能比“出现一种更聪明的软件”要深得多。

因为 Agent 真正改变的，并不只是人与信息之间的关系。

它开始改变：

**谁代表人去行动。**

如果这件事继续向前发展，互联网二十多年来建立起来的商业结构，可能会慢慢发生一次很大的迁移：

从争夺人的注意力，走向争夺人的委托。

而这两种关系，价值完全不同。

### **一、互联网解决的是连接，Agent 开始解决行动**

互联网最早解决的问题很简单。

我不知道一件事情，于是去搜索。

我想找到一个人，于是进入社交网络。

我想买一件商品，于是进入电商平台。

互联网把原本彼此隔开的信息、人和商品连接了起来。

但直到今天，绝大多数互联网产品仍然停在同一个位置：

**它把信息送到你面前，最后的行动仍然由你完成。**

搜索引擎告诉你有哪些机票。

你自己比较。

你自己选择。

你自己付款。

银行 App 告诉你账户里有多少钱。

你自己决定是否转账。

保险公司通知你续费。

你自己研究条款。

你自己比较价格。

你自己决定是否更换。

电商平台把几百件商品摆在你面前，推荐系统试图猜测你的偏好，但最终那个“确认订单”的按钮仍然需要你自己按下。

所以互联网极大降低了“找到东西”的成本，却没有完全消除“完成事情”的成本。

我们每天仍然花费大量时间在：

寻找、比较、确认、沟通、审批、支付、跟进。

这些事情看起来很零碎。

但如果往下抽象一层，会发现它们都属于同一种劳动：

**人在复杂关系网络中寻找一条可以继续前进的路径。**

而 Agent 真正跨越的，就是这一步。

它不再只是告诉你应该怎么做。

它开始能够在获得授权以后，替你去做。

### **二、从“使用软件”，变成“委托软件”**

这看起来只是很小的一步。

实际上关系已经变了。

当我向一个聊天机器人问：

“下周去东京天气怎么样？”

这是一次信息调用。

当它根据我的行程，帮我查找航班和酒店，这是辅助关系。

如果有一天，我告诉它：

“下周去东京三天，预算大约一万元，酒店离会议地点二十分钟以内，还是按照我以前的习惯安排。”

然后它完成：

查航班、

比较价格、

选择时间、

预订酒店、

同步日历、

购买交通票，

甚至根据航班变化自动调整行程，

这时我和它之间的关系已经不是“使用一个工具”。

而是：

**我把一部分行动权交给了它。**

这是非常重要的变化。

因为从这一刻开始，AI 获得的已经不只是我的注意力。

而是我的：

偏好、

历史、

权限、

目标，

以及在某些边界内替我行动的资格。

这就是“委托”。

### **三、委托是有深度的**

而且委托并不是一个开关。

它存在不同深度。

最浅的一层，是咨询。

我问，它答。

这种关系随时可以结束，迁移成本也很低。

再深一点，是长期辅助。

AI 开始了解我的工作方式、语言习惯、项目背景和偏好。

它能够利用过去的上下文帮助我处理新的事情。

再往下一层，是执行。

我允许它访问邮箱、日历、文件、企业系统，甚至在一定条件下完成支付、预订、审批和交易。

到了这里，它已经真正进入我的行为链条。

更深的一层，则是持续代理。

我不再逐条告诉它：

“今天替我做什么。”

而是告诉它：

“我希望达到什么结果。”

例如：

把我的固定订阅费用控制在一个范围内。

当某项服务有更便宜的替代方案时，帮我比较并提醒。

出差按照固定标准预订，不需要每次重新确认。

公司的常规采购在预算以内可以自行处理，超出边界再交给人。

关系从：

**任务驱动**

逐渐变成：

**目标驱动。**

这可能是 Agent 最重要的一次跃迁。

因为到了这里，人交给 AI 的已经不只是一个动作，而是一段持续存在的关系。

### **四、为什么委托关系比流量更值钱**

流量有一个天然的问题。

它很浅和不稳定。

今天一个用户可以刷这个平台，明天也可以去另一个平台。

注意力本身很容易迁移。

所以互联网企业为了维持流量，需要不断获得新的内容、新的刺激、新的推荐和新的用户。

但委托关系不同。

假设一个 Agent 已经知道：

你的工作习惯，

家庭安排，

消费偏好，

出行方式，

风险承受能力，

常用服务，

预算边界，

以及哪些事情可以直接替你决定，哪些必须先问你。

这些信息真正有价值的地方，不在于“数据很多”。

而在于它们共同形成了一套：

**如何代表你行动的关系结构。**

建立这套关系，需要时间。

更重要的是，它会随着使用不断增厚。

这就产生了一种与传统流量完全不同的东西：

**关系资本。**

### **五、真正值得关注的，是关系开始自我强化**

这也是我觉得未来投资最值得注意的一点。

不是所有委托关系都有价值。

真正重要的是那些能够进入正反馈的关系。

它的基本结构可能是：

用户给出更多授权。

AI 因此获得更多上下文。

有了更多上下文，它完成任务的质量提高。

任务完成得越好，用户节省的时间越多。

用户因此产生更多信任。

信任增加以后，又愿意交出更深的授权。

于是形成：

**授权增加→ 上下文增加→ 服务质量提高→ 用户收益提高→ 信任增加→ 授权进一步增加。**

如果这个循环成立，那么企业获得的就不再只是“更多使用量”。

而是一种不断加深的关系。

每一次使用都在增加下一次使用的价值。

每一次授权都提高未来任务的完成能力。

每一次完成都提高用户继续授权的概率。

这就是典型的正反馈结构。

### **六、这可能是一种新的网络效应**

互联网时代我们非常熟悉网络效应。

一个社交网络里的人越多，加入它的价值越高。

一个电商平台上的商家越多，消费者越愿意来；消费者越多，又吸引更多商家。

这是节点数量带来的网络效应。

但 Agent 时代可能出现另一种东西：

**关系深度带来的网络效应。**

一个 Agent 并不一定因为拥有更多用户就一定更强。

真正关键的是：

它能进入多少关系。

能够被授权到什么程度。

可以连接多少系统。

能够调用多少服务。

能够在多少真实行动中代表用户。

假设一个个人 Agent 同时连接：

邮箱、

日历、

银行账户、

支付系统、

购物平台、

航空公司、

酒店、

保险、

医疗服务、

企业软件。

那么新增一个连接，并不只是多增加一个功能。

它可能同时提高其他很多任务的价值。

有了日历，它才能更好地安排航班。

有了支付权限，才能完成预订。

有了历史订单，才能理解偏好。

有了邮箱，又能够读取确认信息和处理变化。

每一个新节点加入以后，原来的节点也变得更有用。

这就是一个典型的关系网络。

### **七、真正的大变化，是 Agent 开始和 Agent 打交道**

如果只是个人使用 AI，我们仍然可以把它理解成一种更先进的软件。

但如果 Agent 继续发展，真正值得注意的下一步也许是：

**Agent 开始和 Agent 发生关系。**

个人的 Agent 与航空公司的 Agent 沟通。

企业采购 Agent 与供应商 Agent 议价。

保险 Agent 与个人财务 Agent 比较方案。

公司的财务 Agent 与银行 Agent 完成对账。

人的旅行 Agent 与酒店、交通、餐厅 Agent 协调行程。

那时候，经济活动的一部分将不再主要是：

人和企业之间交互。

而会变成：

**人的委托代理，与企业的委托代理之间持续发生交互。**

互联网把节点连接起来。

Agent 网络则让节点开始自主行动。

这可能意味着网络本身第一次拥有了一部分“执行能力”。

### **八、从投资角度看，最值得关注的不是“谁有 AI”**

因此，如果从投资角度观察 AI，我觉得未来一个常见误区会是：

看到哪个公司推出 Agent，就认为它进入了 Agent 时代。

这可能远远不够。

真正需要观察的是：

**这个 Agent 有没有形成真实委托。**

第一层，看它是不是只在回答问题。

如果主要仍是生成文字、图片或者建议，那么它与传统软件的差别还没有彻底拉开。

第二层，看用户有没有开始把执行权交给它。

能不能完成一个完整事务，而不是只提供信息。

第三层，看委托深度有没有增长。

从读取信息，

到提出建议，

再到执行，

支付，

持续管理。

如果用户不断把更深的权限交出去，说明关系正在发生变化。

第四层，看这种关系是否存在正反馈。

授权越多，结果是否越好？

结果越好，用户是否愿意继续授权？

每新增一个系统连接，是否能够同时提高其他任务的价值？

第五层，才看这家公司有没有机会成为关系基础设施。

它是否控制：

身份、

权限、

支付、

信任、

协议，

或者 Agent 之间彼此发现和沟通的入口。

到了这一层，它才可能不再只是一个 AI 产品。

而成为新的经济基础设施。

### **九、这里可能出现一种新的杠杆：关系杠杆**

投资里经常讲经营杠杆。

一家软件企业前期投入很大，但增加一个用户的边际成本很低，所以收入增长以后，利润可以更快释放。

Agent 可能带来另一种杠杆。

我暂且把它叫作：

**关系杠杆。**

它的核心不是：

生产一个产品以后可以卖很多次。

而是：

**建立一次关系以后，可以在未来被调用很多次。**

一个用户花时间告诉 Agent：

自己的偏好、

风险边界、

预算、

习惯、

工作方式。

如果这些东西只用于一次任务，那么价值并不大。

但如果它们可以在未来几百次任务里持续生效，第一次建立关系的成本就被不断摊薄。

更有意思的是，关系可能还会随着使用变得更值钱。

它越了解你，

越能替你处理事情；

越能替你处理事情，

你越愿意继续使用；

使用越多，

它又越了解你。

这已经非常接近资本的性质：

**今天建立的结构，可以持续产生未来收益。**

所以高质量的委托关系本身，可能逐渐成为一种资产。

### **十、这也让我们重新理解“财富是什么”**

以前谈财富时，我们容易把财富理解成拥有多少钱。

但资产真正有价值的地方，从来不是它今天静止地摆在那里。

股票之所以有价值，是因为它代表未来现金流。

债券代表未来偿付。

土地代表未来使用与收益。

品牌代表未来消费者选择的概率优势。

信用则意味着，一个人今天能够提前调用未来的资源。

它们背后的共同点其实是：

**对未来资源拥有某种持续调用权。**

从这个角度看，Agent 时代可能产生一种新的关系资产：

**对未来行动的代理权。**

一个平台如果掌握大量用户的身份、偏好、权限、支付方式和长期目标，它拥有的就不只是“数据”。

它占据了一个非常重要的位置：

**行动发生之前的位置。**

广告时代最珍贵的位置，是购买决定发生以前的注意力。

所以所有平台都在争抢屏幕上的几分钟。

Agent 时代真正珍贵的位置，可能进一步提前：

不是影响你如何决定。

而是：

**获得代表你行动的资格。**

这比流量深得多。

### **十一、投资要寻找的，是那些能够持续调用未来的关系**

于是整个逻辑可以连起来。

互联网扩大了连接。

平台把连接变成交易。

AI 降低了理解和处理关系的成本。

Agent 开始获得真实行动的权限。

持续委托让一次性交互变成长期关系。

长期关系又可能通过信任、上下文和授权形成正反馈。

最终，某些企业可能不再仅仅拥有用户。

而是拥有一张：

**可以持续代表用户行动的关系网络。**

这可能是下一阶段非常重要的一类资产。

所以我现在越来越倾向于认为，AI 投资真正值得寻找的，不只是：

模型更大，

参数更多，

用户增长更快，

或者 Token 消耗更多。

这些目前是很重要。

但再往下一层，更值得观察的是：

**谁正在进入人的关系深处。**

谁正在从“被使用”，走向“被委托”。

谁能够让一次授权变成更多授权。

谁能让一个连接增加其他连接的价值。

谁能以极少的新增投入，持续调用越来越大的关系网络。

因为这类结构一旦建立，产生的就不仅是规模。

而是复利。

互联网时代最大的资产曾经是流量。

平台时代最大的资产逐渐变成交易网络。

而 Agent 时代真正稀缺的资产，也许会变成：

**被持续授权的关系。**

如果这个判断成立，那么未来投资真正需要寻找的，不是连接最多的公司。

而是那些能够把连接变成委托，把委托变成信任，再把信任变成持续行动的企业。

因为财富最终追逐的，或许从来不是“拥有更多东西”。

而是拥有这样一种结构：

**用更少的时间、更少的资本和更少的摩擦，持续调用更多的未来。**
