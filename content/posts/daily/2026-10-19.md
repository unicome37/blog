**一句话主线：** 模型调用越来越便宜之后，钱和权限往哪里走成了新问题——Anthropic 拿出 5% 股份设立公益基金，Yelp、Delta 和银行开始对 AI Agent 关门，三星据报借台积电 3nm 工艺制造英伟达定制内存的基底裸片。

## 今日最重要 3 条

**1. Anthropic 设立公益基金，先承诺 5% 股份。** 【官方公告】经股东批准后先投入 5% 股份；估值每比基线增长 50%，董事会可酌情再加 2%。基金是公司全资 LLC，不用于游说与政治捐款。连同创始人与员工既有承诺，合计约 20% 股份用于公益——这是股权承诺，不是已到账的现金，也不能写成「此次直接捐出 20%」。治理结构与估值基线待公布。

**2. 网站开始对 AI Agent 关门。** 【媒体报道】The Verge 10月17日梳理：Yelp 只放行付费数据授权的 Agent；Delta 称没有任何合作允许第三方 Agent 代订机票；摩根大通与嘉信以安全为由阻止 Agent 进入客户账户。各家挡的方式不同（合同、条款或技术拦截），不少设限公司也在推自己的 Agent。

**3. 三星据报用台积电 3nm 制造 NVHBM 基底裸片。** 【媒体报道·公司未确认】路透转述《首尔经济日报》：英伟达要求三家内存厂都用台积电工艺做 NVHBM 基底裸片，三星接受，但标准 HBM 仍自产。NVHBM 架构是 8 月旧闻，新的是供应链分工；量产时间与份额未披露。

## 一、AI 与科技

- **OpenCode 事件后续。** 单一信源称 Console 中存放的 API 密钥被泄露，建议轮换密钥并检查 10月17日以来账单——未经证实，稳妥起见先轮换。
- **FLUX 3 Image Klein（10月15日发布，补记）。** 5.6B 开放权重图像模型，原生 4K、最多 10 张参考图；API 1K 分辨率每张 0.009 美元起。许可为 FLUX Kommunity License，大企业商用需授权。
- **Tether 参投 AIsa（10月15日公告，补记）。** Agent 支付基础设施公司，累计融资超 900 万美元；「25 万个 Agent、1 亿笔交易」为公司口径。
- **决策模型当裁判。** 开发者小实验称与生成式裁判一致率约 90.7%、快 8.6 倍、成本约一半；样本约 20 个 PR，未人工核对。
- **Anthropic 自拟法案后续。** 评论者批评门槛过高、可能压过各州更严法案；草案尚未正式提出。

## 今日观察

三件事问的是同一个问题：AI 创造的价值最后落到谁手里。Anthropic 在股权里划出一块给公众，Yelp 要 Agent 先付数据费，Delta 和银行干脆先不让进。模型调用在变便宜，但进门的权限、关键零件的产能、利润的分配方式不会自动变便宜。让 AI 替你订票、购物、查账户之前，先确认那个网站允许它进去。
