**一句话主线：** 美股财报夜里，AI 开支已经大到要靠公司金融工具来托：Meta 现金流转负、设无投票权 Class C 股；Tesla 车业务在养机器人和 robotaxi；OpenAI 模型开始进入 Google Cloud。

## 今日最重要 3 条

**1. Meta Q3：营收超预期，现金流转负，设 Class C 股。** 【IBD 10-21】Q3 营收 646 亿美元、同比 +26%（预期 633 亿）；2026 资本开支指引 1350–1450 亿美元；Q3 自由现金流 -21.2 亿美元；GAAP EPS 3.83 美元，含 98.9 亿美元诉讼和解。【公司宣布】Class C 股按 1:1 以特别股息派发，2027 年 1 月生效，Zuckerberg 投票权不变。

**2. Tesla Q3：净利降 43%，Optimus 在加州启动量产。** 【路透 10-21】营收 280.5 亿美元（LSEG 预期 278.8 亿），净利 7.87 亿美元、同比降 43%。【TechCrunch 10-21】Optimus 在加州量产，Model S/X 停产。robotaxi 与训练算力时间表为电话会上的公司说法。

**3. OpenAI 模型进入 Google Cloud，两份来源说法不同。** 【Google Cloud 与 OpenAI 官方页】GPT-6 系列进入 Model Garden 私有预览，Antigravity 集成等待上线；【二手转述】称「未来几周内」正式可用。以官方页为准。
