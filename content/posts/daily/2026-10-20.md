**一句话主线：** 美国联邦文职机构被要求清除 DeepSeek 及相关第三方产品；AI 成本竞争从通用 API 拆到专用小模型、芯片软件栈与 Agent 沙箱；同一套行动能力已被用于野外入侵。

## 今日最重要 3 条

**1. 美国 DHS 下令联邦文职机构移除 DeepSeek。** 【官方令】Exclusion and Removal Order #2026-01：禁止采购 DeepSeek 及关联公司产品，并要求从 IT 系统移除现有产品及「基于 DeepSeek 构建的第三方产品」。部长 7月24日签署，10月19日公开，联邦公报 10月20日刊登，依据为 2018 年 FASCSA。覆盖下游第三方产品，是供应链安全令首次对准中国前沿 AI 实验室。

**2. MiniMax 发布 M3.1 Flash，低价 Agent API 已可用。** 【公司公告】确认隐身公测「Space Bunny」即其早期版；每百万 token 输入/输出 0.15/0.60 美元，权重仍待开放。独立评测 Artificial Analysis：智能指数 42（低于 DeepSeek V4.1 Flash 1017 的 45），AutomationBench-AA 73%（高于后者 67%）——看任务，不看总榜。

**3. NorForge：黑客已在用 AI Agent 实施入侵。** 【调查报告·路透核实】20 多个公网暴露的 AI 渗透测试控制面板被用于恶意行动；路透确认目标包括 Deere、SharkNinja、Cummins 等网站。行动能力继续跑在治理前面。

## 一、AI 与科技

- **Tenstorrent 15 亿美元 E 轮，估值 62 亿美元。** 资金扩产 Galaxy 服务器；CEO 据报拒绝英特尔/高通约 50 亿美元收购意向（TechCrunch 口径）。
- **Mercury 3 / Cloudflare Clairic / 微软 Scope / TorchNeuron / Modal Vera。** 扩散式低延迟模型、抽取专用模型、Agent 评测平台、Trainium 软件栈、Agent 沙箱 CPU——成本战扩到执行层。
- **doubleAI Maxwell「代码执行模型」。** Nvidia 背书，公司称早期客户降本约 67%（单客户口径）。
- **FLUX 3 Max、Together AI 上线 DeepSeek Flash、Dream-1 机器人 API。** 视频速度竞争、推理云扩容、机器人接口可测但非安全关键生产。
